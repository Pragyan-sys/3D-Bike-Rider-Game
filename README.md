
# 🏍️ 3D Bike Rider Game

A browser-based **3D bike racing game** developed using **HTML, CSS, JavaScript, and Three.js**. The game provides an interactive 3D riding experience with real-time movement, speed control, obstacles, and game mechanics.

## 🎮 Features

- 🏍️ 3D Bike Model
- 🌐 Real-time 3D graphics using Three.js
- 🚦 Dynamic road environment
- ⚡ Speed and acceleration system
- ❤️ Bike health system
- ⛽ Nitro boost system
- 🎯 Distance tracking
- 🎮 Keyboard controls
- 🔊 Game sound controls
- ⏸️ Pause and resume functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL
